Set up profile capture

Do this once. The dark button below becomes your browser bookmark.

Drag this to bookmarks bar
  1. Press Cmd + Shift + B to show Chrome's bookmarks bar.
  2. Drag the dark button into that bookmarks bar.
  3. Open a LinkedIn/profile page.
  4. Select useful text, then click your new bookmark.
  5. Your existing Workbench tab will update in the background, and the page will appear in Capture ready for Create profile.

If drag does not work, copy this code, press Cmd + D, click Edit, and replace the bookmark URL with it.
